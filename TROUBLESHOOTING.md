# Решение проблем с Gemini API

## Ошибка квоты (429 / RESOURCE_EXHAUSTED)

### Проблема
Если вы видите ошибку:
```
Ошибка Gemini: You exceeded your current quota...
Quota exceeded for metric: generativelanguage.googleapis.com/generate_content_free_tier_requests
```

### Причины
1. **Используется модель, недоступная в бесплатном тарифе**
   - `gemini-3-pro` - доступна только в платном тарифе
   - `gemini-3-pro-preview` - доступна только в платном тарифе
   - `gemini-1.5-pro` - доступна только в платном тарифе

2. **Превышен лимит запросов**
   - Дневной лимит бесплатного тарифа
   - Минутный лимит запросов

### Решение

1. **Переключите модель на доступную в бесплатном тарифе:**
   - Откройте боковую панель (кнопка меню слева вверху)
   - Перейдите на вкладку "Настройки"
   - Найдите раздел "Провайдер AI" → "Gemini"
   - Выберите модель:
     - ✅ **Flash 2.5** (`gemini-2.5-flash`) - рекомендуется
     - ✅ **Flash 1.5** (`gemini-1.5-flash`) - альтернатива
   
2. **Проверьте текущую модель:**
   - Убедитесь, что не используется `gemini-3-pro` или `gemini-1.5-pro`
   
3. **Подождите:**
   - Если превышен минутный лимит, подождите 1-2 минуты
   - Если превышен дневной лимит, подождите до следующего дня

4. **Проверьте лимиты:**
   - Откройте https://ai.dev/usage?tab=rate-limit
   - Проверьте, какие модели доступны в вашем тарифе

### Доступные модели в бесплатном тарифе

✅ **Доступны:**
- `gemini-2.5-flash`
- `gemini-1.5-flash`
- `gemini-2.5-flash-image` (для генерации изображений)

❌ **Недоступны:**
- `gemini-3-pro`
- `gemini-3-pro-preview`
- `gemini-1.5-pro`

## Генерация изображений

### Проблема
Если вы видите ошибку при попытке сгенерировать изображение:
```
Ошибка при генерации изображения: Превышен лимит запросов для генерации изображений...
Генерация изображений недоступна в бесплатном тарифе...
```

### Причины
1. **Генерация изображений недоступна в бесплатном тарифе Gemini API**
   - Модель `gemini-2.5-flash-image` может быть недоступна или иметь очень строгие ограничения
   - Функция генерации изображений может требовать платный тариф

2. **Превышен лимит запросов**
   - Даже если модель доступна, может быть превышен дневной/минутный лимит

### Решение

#### ✅ Альтернативные методы генерации визуализаций:

1. **Детерминированные графики (встроено в редактор)**
   - Выделите текст с данными в редакторе
   - Откройте контекстное меню (правой кнопкой мыши)
   - Выберите "Вставить график" или "Вставить диаграмму"
   - Формат данных: `Название, Значение1, Значение2, ...`
   
   Пример:
   ```
   Продажи: Январь 100, Февраль 150, Март 200
   ```

2. **Таблицы HTML**
   - Выделите текст с табличными данными
   - Откройте контекстное меню
   - Выберите "Вставить HTML таблицу"
   - Формат: данные через запятую или табуляцию

3. **Диаграммы (GraphViz)**
   - Выделите текст со связями (например: "A -> B, B -> C")
   - Откройте контекстное меню
   - Выберите "Вставить диаграмму"

4. **Загрузка изображений вручную**
   - Скопируйте изображение из другого источника
   - Вставьте в редактор (Ctrl+V)
   - Или используйте контекстное меню → "Вставить изображение"

#### ❌ Если генерация изображений критична:

1. **Перейдите на платный тариф Gemini API**
   - Проверьте доступность генерации изображений на https://ai.google.dev/pricing

2. **Используйте сторонние сервисы**
   - DALL-E, Midjourney, Stable Diffusion и другие
   - Сгенерируйте изображение там и загрузите в редактор

## Другие ошибки

### Ошибка доступа (403)
- Проверьте, что API ключ правильный
- Убедитесь, что API ключ активирован
- Проверьте настройки доступа в Google AI Studio

### API ключ не настроен
- Установите переменную окружения `GEMINI_API_KEY`
- Получите ключ на https://aistudio.google.com/app/apikey
