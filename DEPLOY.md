# Инструкция по деплою на Netlify

## Быстрый старт

1. **Подготовьте репозиторий**
   - Загрузите код в GitHub/GitLab/Bitbucket

2. **Создайте сайт на Netlify**
   - Зайдите на https://app.netlify.com/
   - Нажмите "Add new site" → "Import an existing project"
   - Выберите ваш репозиторий

3. **Настройте переменные окружения**
   - В настройках сайта: Site settings → Environment variables
   - Добавьте: `GEMINI_API_KEY` = `ваш_api_ключ`
   - Получить ключ: https://aistudio.google.com/app/apikey

4. **Настройки сборки** (уже настроены в `netlify.toml`)
   - Build command: `npm run build`
   - Publish directory: `dist`

5. **Деплой**
   - Нажмите "Deploy site"
   - Дождитесь завершения сборки

## Проверка деплоя

После успешного деплоя:
- ✅ Проверьте, что сайт открывается
- ✅ Попробуйте использовать AI функции
- ✅ Если возникают ошибки, проверьте переменные окружения в Netlify

## Troubleshooting

**Ошибка: API ключ не работает**
- Убедитесь, что переменная `GEMINI_API_KEY` установлена в Environment Variables
- Проверьте, что ключ правильный (без лишних пробелов)
- Перезапустите деплой после изменения переменных

**Ошибка 404 при обновлении страницы**
- Проверьте, что `netlify.toml` содержит redirect правило `/* -> /index.html`

**Ошибка сборки**
- Проверьте, что Node.js версия совместима (рекомендуется 18+)
- Проверьте логи сборки в Netlify

## Переменные окружения

Обязательные:
- `GEMINI_API_KEY` - API ключ для Gemini API

Опциональные (для локальной разработки):
- Создайте `.env.local` файл с переменными
