# Изоляция данных пользователей

Приложение поддерживает изоляцию данных для каждого пользователя. Каждый пользователь имеет свои собственные документы, настройки, базу знаний и историю чата.

## Как это работает

### Автоматическое создание пользователя

При первом запуске приложения автоматически создается новый пользователь с уникальным идентификатором (UUID). Все данные сохраняются в localStorage с префиксом, содержащим ID пользователя.

### Управление пользователями

В правом верхнем углу заголовка приложения находится кнопка с именем текущего пользователя. При клике открывается меню управления пользователями.

#### Возможности:

1. **Просмотр всех пользователей**
   - Список всех созданных пользователей
   - Отображение текущего пользователя
   - Дата создания каждого пользователя

2. **Переключение между пользователями**
   - Кликните на иконку входа рядом с именем пользователя
   - При переключении происходит перезагрузка страницы
   - Загружаются данные выбранного пользователя

3. **Создание нового пользователя**
   - Кнопка "Создать нового пользователя"
   - Введите имя нового пользователя
   - Новый пользователь автоматически становится текущим

4. **Редактирование имени пользователя**
   - Кликните на иконку редактирования рядом с именем
   - Измените имя
   - Сохраните изменения

## Изолированные данные

Каждый пользователь имеет отдельные:

- ✅ **Документы** - содержимое редактора и название документа
- ✅ **Настройки AI** - конфигурация моделей и провайдеров
- ✅ **База знаний** - эталонные документы и документы базы знаний
- ✅ **История чата** - все сообщения с AI ассистентом
- ✅ **Тема оформления** - светлая или темная тема

## Технические детали

### Хранение данных

Все данные хранятся в `localStorage` с ключами вида:
```
user_{userId}_{dataKey}
```

Например:
- `user_123-abc_editor_content` - содержимое документа пользователя
- `user_123-abc_config` - настройки AI
- `user_123-abc_kb_items` - база знаний

### Миграция старых данных

При первом запуске новой версии приложения:
- Старые данные из `localStorage` (без префикса пользователя) автоматически переносятся в хранилище текущего пользователя
- Старые ключи удаляются после успешной миграции

### Безопасность

⚠️ **Важно понимать:**

1. **Локальное хранение** - данные хранятся только в браузере пользователя
2. **Нет серверной синхронизации** - при очистке данных браузера данные теряются
3. **Доступ с одного устройства** - каждый браузер/устройство имеет свои данные
4. **Нет шифрования** - данные хранятся в открытом виде в localStorage

Для полноценной изоляции данных между компьютерами требуется:
- Серверная часть с базой данных
- Аутентификация пользователей
- Синхронизация данных через API

## Использование

### Создание нового пользователя для другого человека

1. Кликните на имя текущего пользователя в правом верхнем углу
2. Нажмите "Создать нового пользователя"
3. Введите имя нового пользователя (например, "Иван")
4. Готово! Новый пользователь создан и автоматически активирован

### Переключение между пользователями

1. Кликните на имя пользователя
2. В списке найдите нужного пользователя
3. Кликните на иконку входа рядом с его именем
4. Страница перезагрузится, и вы увидите данные выбранного пользователя

### Редактирование имени

1. Откройте меню пользователей
2. Найдите нужного пользователя
3. Кликните на иконку редактирования
4. Измените имя и нажмите галочку для сохранения

## Удаление данных пользователя

Для удаления всех данных конкретного пользователя:

1. Откройте консоль разработчика (F12)
2. Выполните:

```javascript
// Замените USER_ID на ID пользователя (можно найти в localStorage)
const userId = 'USER_ID';
const keys = Object.keys(localStorage);
keys.forEach(key => {
  if (key.startsWith(`user_${userId}_`)) {
    localStorage.removeItem(key);
  }
});
// Также удалите информацию о пользователе
localStorage.removeItem(`user_${userId}`);
// Удалите из списка всех пользователей
const allUsers = JSON.parse(localStorage.getItem('all_users') || '[]');
const filtered = allUsers.filter(u => u.id !== userId);
localStorage.setItem('all_users', JSON.stringify(filtered));
```

⚠️ **Внимание:** Это действие необратимо!

## FAQ

**Q: Можно ли использовать один аккаунт с разных компьютеров?**  
A: Нет, данные хранятся только локально в браузере. Для синхронизации между устройствами нужен сервер.

**Q: Что происходит при очистке кеша браузера?**  
A: Все данные удаляются, включая всех пользователей и их документы.

**Q: Можно ли экспортировать данные пользователя?**  
A: Пока нет встроенной функции, но можно экспортировать документы через меню "Файл" → "Экспорт".

**Q: Сколько пользователей можно создать?**  
A: Технически неограниченно, но ограничено размером localStorage браузера (обычно 5-10 МБ).
